= Preparing your environment

Get OpenShift, Ansible Automation Platform, the collection, and the inventory in place before you seed. AAP is the place you run Migration Factory after that. Laptop CLI is only for these setup steps (and for deploying AAP if you do not already have it).

Work through the children in the left nav:

. xref:prerequisites.adoc[Prerequisites] — access and credentials.
. xref:migration-factory-prerequisites.adoc[Migration Factory prerequisites] — local tools, only if you still need them.
. xref:source-collection.adoc[Sourcing the collection and execution environment].
. xref:confirm-openshift-ready.adoc[OpenShift] — Virtualization and MTV already installed.
. xref:setup-aap-yourself.adoc[Ansible Automation Platform] — use the AAP you already run.
. xref:configure-inventory.adoc[Building your inventory].
. xref:setup-existing-ocp.adoc[Deploying Ansible Automation Platform] — use this only if AAP is not installed yet.
. xref:validate-environment.adoc[Validate your environment].

Then xref:seed-aap.adoc[Seeding Ansible Automation Platform].

Red Hat Demo Platform is a demonstration lab, not this path. It lives under *Enablement* → xref:setup-rhdp.adoc[RHDP workshop].
