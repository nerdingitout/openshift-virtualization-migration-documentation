= Create providers

Register the source hypervisor with Migration Toolkit for Virtualization so later steps can map networks and storage and run a wave. Seed must already have succeeded (xref:seed-aap.adoc[Seed Migration Factory into AAP]).

When you are done, MTV shows a provider with a green check in the `openshift-mtv` namespace. Next is xref:create-maps.adoc[Create maps].

You can configure these MTV providers:

* VMware, using the link:https://console.redhat.com/ansible/automation-hub/repo/validated/infra/openshift_virtualization_migration/content/playbook/mtv_provider_vmware.yml/[`mtv_provider_vmware`] playbook.
* Red Hat Virtualization, using the link:https://console.redhat.com/ansible/automation-hub/repo/validated/infra/openshift_virtualization_migration/content/playbook/mtv_provider_ovirt.yml/[`mtv_provider_ovirt`] playbook.

The playbooks use the `mtv_management` role. After seed, the same work can run from AAP instead of `ansible-navigator`.

== Prerequisites

* Logged in to the cluster over CLI with `oc login`.
* The cluster is ready for OpenShift Virtualization Migration (xref:confirm-openshift-ready.adoc[Confirm OpenShift is ready]).
* Inventory matches the environment (xref:configure-inventory.adoc[Configure inventory for your environment]).

=== Required variables

* *mtv_management_migration_targets (Required)*: details about the VMware or RHV environment.

The following example configures a VMware provider in a `var.yml` file:

.var.yml
[source,yaml]
----
mtv_management_migration_targets:
- name: vmware-2w7dj
  type: vmware
  host: vcsrs00-vc.infra.demo.redhat.com
  username: ocpvirt-2w7dj-user1@infra
  password: <VCENTER-PASSWORD>
  vddk:
  image: quay.io/redhat-cop/openshift-virtualization-migration-vddk:latest #this VDDK image is for demo purposes only. Must NOT be distributed externally.
  username: "{{ container_username }}"
  password: "{{ container_password }}"
  sdkEndpoint: /sdk
  insecureSkipTlsVerify: true
  mapping:
    create: true
----

The following example configures a RHV provider in a `var.yml` file:

.var.yml
[source,yaml]
----
mtv_management_migration_targets:
- name: rhev-target-1 # Required
  type: ovirt
  host: rhev.infra.demo.redhat.com
  username: admin@internal
  sdkEndpoint: /ovirt-engine/api #if not provided automatically will be added
  password: <RHEV-PASSWORD>
  insecureSkipTlsVerify: true
  mapping:
    create: true
----

These values should match the VMware or RHV connection you already described in the inventory.

== Create providers from the CLI

[,shell]
----
ansible-navigator run --eei=quay.io/redhat-cop/openshift-virtualization-migration-ee:latest --pp=missing -m stdout --pae=false --senv=K8S_AUTH_HOST=$(oc whoami --show-server) --senv=K8S_AUTH_VERIFY_SSL=false --senv=K8S_AUTH_API_KEY=$(oc whoami -t) infra.openshift_virtualization_migration.mtv_provider_vmware -e openshift_api_key=$(oc whoami -t) -i <inventory> --extra-vars "@var.yml"
----

Use `mtv_provider_ovirt` instead of `mtv_provider_vmware` when the source is RHV.

== Create providers with AAP

After seed, AAP has the workflow that registers MTV providers.

. In AAP, open *Templates* under *Automation Execution* and launch *Configure OpenShift Virtualization Migration* (rocket icon).

image::guides:rhdp:aap-launch-virtualization-migration-workflow.png[Launch the Configure OpenShift Virtualization Migration Workflow Job Template]

. Wait until the Target Configuration node succeeds.

image::guides:rhdp:aap-workflow-configure-target.png[Configure Migration Target Workflow]

. In the OpenShift web console, open *Migration* → *Providers for virtualization*. The provider is in the `openshift-mtv` namespace. A green check means the connection is valid.

image::guides:rhdp:openshift-mtv-providers.png[MTV Providers]

[NOTE]
====
The `openshift-mtv` namespace may not appear in the Project dropdown. Select *Show default projects* so projects that start with `openshift` are listed.
====

Confirm a Secret for the VDDK image exists in `openshift-mtv` (*Workloads* → *Secrets*). Do not use this page to create NetworkMaps or StorageMaps; that is xref:create-maps.adoc[Create maps].

== When you are done

MTV has a provider for the source hypervisor. Continue to xref:create-maps.adoc[Create maps].
