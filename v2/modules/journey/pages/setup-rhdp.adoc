= RHDP workshop

Red Hat Demo Platform is a **demonstration lab**, not the default path. Production and customer work starts at xref:setup-environment.adoc[Preparing your environment] with your OpenShift and AAP.

Use this catalog item only for enablement: a short-lived OpenShift cluster with Virtualization and MTV, plus a vSphere source. It does not install AAP.

Catalog item: https://catalog.demo.redhat.com/catalog?item=babylon-catalog-prod/openshift-cnv.ocp-virt-roadshow-multi-user.prod&utm_source=webapp&utm_medium=share-link[Experience OpenShift Virtualization Roadshow].

== Order and collect details

. Order the item. Activity: **Practice / Enablement**. Purpose: **Conduct internal training/enablement**.
. When the service is ready, open **Details** and copy the OpenShift API and console URLs, **admin** password, and vCenter host, username, and password.

image::guides:rhdp:rhdp-service-details.png[RHDP service details]

Then follow the same mainstream path: optional xref:setup-existing-ocp.adoc[Deploying Ansible Automation Platform (optional)], xref:configure-inventory.adoc[Building your inventory] (one cluster, one source), xref:seed-aap.adoc[Seeding Ansible Automation Platform].

The older workshop write-up remains at xref:guides:rhdp:rhdp.adoc[v1 RHDP workshop]. Do not use its `migration_factory_aap` playbook or hub/spoke inventory; collection `v2` does not use those.
