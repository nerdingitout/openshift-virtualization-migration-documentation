= Ansible for OpenShift Virtualization Migration
:page-aliases: home.adoc

Ansible for OpenShift Virtualization Migration (**Migration Factory**) is a set of Ansible playbooks with deep integration into Ansible Automation Platform (AAP). It moves virtual machines from existing hypervisors onto Red Hat OpenShift Virtualization. After seed, **AAP is the control plane** for providers, maps, and waves.

These pages describe the collection `v2` branch. Use the left nav in this order:

. xref:journey:setup-environment.adoc[Preparing your environment]
. xref:journey:seed-aap.adoc[Seeding Ansible Automation Platform]
. xref:journey:run-a-migration.adoc[Performing a migration wave]
. xref:journey:execute-migration.adoc[Migrating VMs]
. xref:journey:verify-migration.adoc[Post migration]

*Enablement* (RHDP workshop) is a demo lab, not the main path. *Automation reference* lists the `v2` roles. Role READMEs stay in Git for now; they are not copied into this site.

The intended public URL for this documentation is link:https://red.ht/migration-factory[red.ht/migration-factory] (and a docs-specific shortlink when it is published). The current published v1 workshop still lives at xref:guides::home.adoc[Development Guides (v1)] until that content is archived.

== Overview

Migration Factory uses MTV on the destination cluster and AAP to repeat the same sitting across sources and clusters: assess, map, plan a wave, migrate, verify, archive.
